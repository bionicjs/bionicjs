# BionicJS Documentation

This site hosts the BionicJS documentation: guides, learn modules, and the changelog.

## Stack

- Next.js (App Router) with React 19
- Tailwind CSS v4
- Shiki for syntax highlighting

## Development

```sh
npm run dev
```

Open http://localhost:3000 to view the site.

## Structure

- app/: routes for the home page, docs, learn modules, changelog, and llms.txt
- components/: the site shell, icons, and learn module components
- lib/: shared helpers

The site is a private workspace package and is not published to npm.
